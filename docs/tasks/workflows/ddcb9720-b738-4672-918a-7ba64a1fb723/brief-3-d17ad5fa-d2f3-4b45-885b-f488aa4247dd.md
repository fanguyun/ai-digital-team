## 研究问题

固定串行 Agent 工作流如何落实人工确认、独立核验与幂等入库？后续研究需回答：

1. **状态与边界**：如何区分节点产出完成、研究任务完成、等待人工确认、外部写入完成和写入结果待核验？各状态以什么证据为准？
2. **人工确认**：确认应设在哪些节点？如何绑定确认人、具体动作、目标位置和产物版本？拒绝、返工、内容变更及重复确认时如何处理？
3. **独立核验**：如何独立检查来源、结论和验收标准？核验不通过时退回哪里，如何防止未通过的版本进入写入节点？
4. **持久化与恢复**：等待确认、进程中断、超时和重试后，如何恢复到正确节点并保留确认与核验结果？
5. **幂等入库**：如何确定稳定的幂等键及版本规则？如何处理重复触发、并发请求、写入成功但响应丢失、部分成功及内容更新，并取得可核对的入库证据？
